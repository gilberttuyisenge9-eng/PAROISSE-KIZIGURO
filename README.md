# Parruwasi ya KIZIGURO

Website yerekana ibikorwa n'amakuru ya Parruwasi ya KIZIGURO.

## Technologies
- HTML5
- CSS3

## Features
- Responsive layout
- Sections: Amakuru, Serivisi, Santarale & Succursales, Contact
- Clean and professional design

## Santarale & Succursales
- **Santarale ya Kiziguro:** Kiziguro, Gorora, Gishya, Rugarama, Murambi  
- **Santarale ya Gakenke:** Gakenke, Rubona, Gakoni, Kiramuruzi  
- **Santarale ya Nyabisindu:** Nyabisindu  
- **Santarale ya Rwimitereri:** Rwimitereri, Gashya, Kabweja, Kasi  
- **Santarale ya Rwankuba / Kimironko:** Kimironko, Rugombe, Nyaruhinga
